🎬 KIRAFLIX — Sua experiência de entretenimento

O KIRAFLIX é uma plataforma de entretenimento com uma interface moderna, inspirada nos principais serviços de streaming. Seu objetivo é reunir filmes e séries em um só lugar, com navegação intuitiva, categorias personalizadas e uma experiência adaptada para dispositivos móveis e computadores.

✨ Funcionalidades

- 🎥 Catálogo de filmes e séries.
- 🔗 Reprodução por links de vídeo e players externos compatíveis.
- 🗂️ Categorias e abas personalizadas.
- 🆕 Identificação de novidades e lançamentos.
- 🛠️ Painel administrativo para gerenciar o catálogo.
- ✏️ Opções para adicionar, editar e excluir títulos.
- 🖼️ Personalização de capas e imagens de perfil.
- ☁️ Integração planejada com Supabase para compartilhar atualizações do catálogo.
- 📱 Interface responsiva para celular e computador.

🧰 Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase
- GitHub Pages

🚀 Publicação

O projeto pode ser publicado pelo GitHub Pages, utilizando o arquivo "index.html" na raiz do repositório.

⚠️ Observações

A reprodução depende da compatibilidade e disponibilidade dos players externos utilizados. A integração com o Supabase exige configuração das credenciais, das tabelas e das políticas de segurança.

Publique somente conteúdos que você tenha autorização para disponibilizar.
